# Varadharaja Cinemas

Client-demo website for Varadharaja Cinemas, Chitlapakkam, Chennai.

## Current build
- Premium dark/gold cinema design
- Logo-only responsive navigation
- Now Showing / showtime cards
- 4K RGB Laser and Dolby Atmos experience
- Four-screen section
- Cinema history / story
- Abinta food brand section
- Reviews section
- Location and Google Maps link
- Responsive mobile layout

## Deployment
This is a static site and can be deployed directly to Vercel with the repository root as the project directory. No build command is required.

## Planned production modules
- Supabase database
- Secure admin login
- Movie/poster management
- Showtime management
- Screen management
- Abinta menu and pricing management
- Gallery
- Offers and announcements
- Reviews moderation
- SEO management
- Enquiry management
- Analytics
- Ticket booking integration

The public website must never expose CMS/admin controls. Admin functionality will live behind an authenticated `/admin` area in the production build.
